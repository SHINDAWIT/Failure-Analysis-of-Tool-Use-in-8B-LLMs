# 자료 출처와 공개용 변경

## 기준 자료

- 제공된 연구 자료 묶음: cisc-w26-wsl-transfer.zip
- 공개 PDF: CISC-W_2026_paper__196.pdf
- 입력 PDF 식별: CISC-W_2026_paper__196 (2).pdf

논문 제목은 「8B LLM의 도구 사용 실패 분석: 형식 준수, 행동 선택 및 실행 종료」입니다. 공개 PDF는 제공된 파일의 바이트를 유지하고 파일명만 요청된 형태로 정리했습니다. (2)라는 파일명이나 이 저장소의 게시일로 학회 제출 최종본·채택·발표 여부를 확정하지 않습니다.


자료 묶음과 개별 파일의 전체 해시는 [publication_manifest.json](../publication_manifest.json)에 있습니다.

## 원본 그대로 공개한 자료

실험 패키지의 Python 소스, 선택한 실행·준비·집계 스크립트, 도구 스키마와 종료 상태 그림은 원본 바이트를 유지했습니다. 보존 코드의 주석이나 진단 설명이 현재 논문의 보수적인 해석보다 강할 수 있습니다. 해석 범위는 [실험 방법·한계](methodology.md)를 따릅니다.

원본 자료에 없던 과거 구현·테스트 이력을 새로 만들지 않았습니다. 현재 공개본의 함수별 개인 작성 범위를 Git 게시 이력만으로 추정하지 않습니다.

## 공개를 위해 새로 작성하거나 정리한 자료

- 한국어·영어 README, 코드 안내, 실험 방법·재현·출처 문서
- 별도로 작성한 한국어 프로젝트 소개서
- 표 전사값과 저장 요약의 집계 투영 JSON
- 공개 표·해시·문법을 확인하는 verify_public_results.py
- f0.json: 실행 코드가 읽는 설정을 유지하되 로컬 모델 경로를 상대경로로 정리하고 공개용 템플릿임을 표시
- selected.json: 해당 두 벤치마크의 ID·선정 방식만 투영하고 문항 본문·정답·관련 없는 보조 단계를 제외

이는 공개용 편집·검산이며 새 연구 결과가 아닙니다. 두 설정 파일을 손대지 않은 원래의 사전 고정 manifest로 표시하지 않습니다.

## 배포 범위

원시 모델 출력, 원시 실행 원장, 비공개 정답 파일, 벤치마크 문제 본문, 모델 가중치, 복제한 평가 저장소와 개인 검토용 전달 메모는 포함하지 않았습니다. 공개 수치는 논문과 보존 요약을 바탕으로 한 집계입니다.

전체 연구 코드를 새로 실행하거나 GPU 추론·부트스트랩을 재실행하지 않았습니다. 공개용 검산의 실행 결과를 연구 당시 테스트 통과로 바꾸지 않습니다.

## 코드·논문 사이에 남은 차이

1. repair_json_text()는 숫자 뒤 큰따옴표와 후행 쉼표를 처리합니다. 논문은 전자를 중심으로 진단 조건을 설명합니다. 실행 당시 버전과 추가 규칙의 실제 영향은 확정하지 않았습니다.
2. native XML은 출력 규약과 프롬프트 도구 목록이 다릅니다. 공통 스키마에는 프롬프트에 제시되지 않은 도구도 남아 있어 목록과 파서 허용 범위를 구분합니다.
3. 과거 일부 진단 요약의 강한 원인 해석은, 예산 부족과 종료 판단을 구분할 수 없다는 제공 PDF의 한계 설명으로 제한합니다.
4. 일부 중간 출력과 도구 반환 본문이 보존되지 않았습니다. 부분 원장을 완전한 추적 기록으로 표현하지 않습니다.
