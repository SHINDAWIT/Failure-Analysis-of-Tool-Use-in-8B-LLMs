## 배포 범위

원시 모델 출력, 실행 원장, 정답 파일, 벤치마크 문제 본문, 모델 가중치와 복제한 평가 저장소는 포함하지 않았습니다. 공개 수치는 논문과 저장된 요약을 바탕으로 한 집계이며, 검산 도구는 표의 산술·집계 대응·파일 무결성을 검사합니다.

## 코드·논문 사이에 남은 차이

1. repair_json_text()는 숫자 뒤 큰따옴표와 후행 쉼표를 처리합니다. 논문은 전자를 중심으로 진단 조건을 설명합니다. 실행 당시 버전과 추가 규칙의 실제 영향은 확정하지 않았습니다.
2. native XML은 출력 규약과 프롬프트 도구 목록이 다릅니다. 공통 스키마에는 프롬프트에 제시되지 않은 도구도 남아 있어 목록과 파서 허용 범위를 구분합니다.
3. 일부 진단 주석은 종료 원인을 강하게 해석하지만, 논문은 탐색 예산 부족과 종료 판단의 영향을 구분하기 어렵다는 한계를 설명합니다.
4. 일부 중간 출력과 도구 반환 본문이 보존되지 않아 전체 실행 경로의 추적에는 제약이 있습니다.
