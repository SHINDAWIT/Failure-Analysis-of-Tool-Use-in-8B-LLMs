# Configuration and selected identifiers

- loc_tools.json is copied unchanged from the research archive.
- f0.json is a publication-time template derived from the archived settings. Model paths use a relative models/ directory, editorial metadata is removed, and the file is explicitly marked as a template.
- selected.json is an identifier-only projection. It preserves the selected 40 When2Call IDs and the initial 29 Loc-Bench Security IDs, and names the one excluded Loc item for the common 28-item comparison. It contains no question bodies or gold labels.

These two projections are not untouched historical freeze manifests. Source hashes and modifications are recorded in [the publication manifest](../../../publication_manifest.json).
