# Upstream resources

This research uses existing models, an inference runtime, and benchmark resources. Their weights, raw benchmark payloads, gold answers, and cloned evaluation repositories are not distributed here.

| Resource | Role | Upstream |
| --- | --- | --- |
| llama.cpp | Local inference server | [ggml-org/llama.cpp](https://github.com/ggml-org/llama.cpp) |
| IBM Granite 4.2-8B | Existing model evaluated in the study | [Model repository](https://huggingface.co/ibm-granite/granite-4.2-8b) |
| Ministral-8B-Instruct-2410 | Existing model evaluated in the study | [Model repository](https://huggingface.co/mistralai/Ministral-8B-Instruct-2410) |
| When2Call | Tool-use action selection benchmark | [nvidia/When2Call](https://huggingface.co/datasets/nvidia/When2Call) |
| Loc-Bench V1 | Security code-localization subset | [czlll/Loc-Bench_V1](https://huggingface.co/datasets/czlll/Loc-Bench_V1) |

The paper contains the research references. This publication does not assign a new repository-wide software license or replace the terms supplied by upstream providers.
